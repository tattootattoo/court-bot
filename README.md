# ⚖️ محكمة فكّك عقلك — بوت تيليجرام

لعبة جماعية للقروبات: قضية طريفة، ومتهم قد يكون مذنباً وقد يكون بريئاً، وكل لاعب له **دور** يُوزَّع **عشوائياً**.
المرافعات والتصويت والنتائج **علنية في القروب**، أما **أسرار الأدوار** (الحقيقة، الأدلة، الفحص، الرشوة…) فتصل كل لاعب **سرّاً في الخاص** مع البوت.

> لا يحتاج أي مكتبة خارجية — بايثون 3.9+ فقط.

## التشغيل السريع

1. من [@BotFather](https://t.me/BotFather) أنشئ بوتاً بـ `/newbot` وانسخ التوكن.
2. شغّل البوت:
   ```bash
   cp .env.example .env        # ضع التوكن في BOT_TOKEN
   python3 court_bot.py
   ```
   (أو مباشرة: `BOT_TOKEN=123:ABC python3 court_bot.py`)
3. أضف البوت إلى القروب — **لا يحتاج صلاحيات أدمن**، ووضع الخصوصية (Privacy Mode) يبقى مفعّلاً.
4. اكتب `/court` في القروب ← يظهر زر **✋ انضم**. من لم يفعّل البوت من قبل يحصل على رابط يفتح محادثة البوت (يضغط Start مرة واحدة).
5. حين يكتمل العدد (5 على الأقل) يضغط المضيف **▶️ ابدأ المحكمة**.

جرّب اللعبة بدون تيليجرام أصلاً: `python3 demo.py` (أو `python3 demo.py -n 9 --dm` لإظهار كل الرسائل الخاصة).

## كيف تُلعب؟

**الأدوار** (تُعلن الأدوار العلنية في القروب، وتبقى التفاصيل السرّية في الخاص):

| الدور | علني؟ | سرّه الخاص |
|---|---|---|
| 👨‍⚖️ القاضي | نعم | أسئلة مقترحة للاستجواب؛ صوته يحسم التعادل |
| 🗣️ المدّعي العام | نعم | 3 أدلة سرّية يعرض منها دليلين علناً بزر |
| 🛡️ محامي الدفاع | نعم | 3 أدلة سرّية يعرض منها دليلين علناً بزر |
| 🔒 المتهم | نعم | يعرف إن كان مذنباً أم بريئاً + قصته الحقيقية |
| 👁️ شاهد عيان صادق | «شاهد» | يعرف الحقيقة ويقولها |
| 🤥 شاهد زور | «شاهد» | يعرف الحقيقة ومهمته أن يقول عكسها |
| 👥 محلّف | «محلّف» | يسمع ويحلّل ويصوّت |
| 🕵️ محلّف محقق (من 8 لاعبين) | «محلّف» | فحص واحد يكشف له هل شاهد معيّن كاذب |
| 💰 محلّف مرتشٍ (من 10 لاعبين) | «محلّف» | رشوة لصالح «مذنب» أو «بريء»: مكافأة إن جاء الحكم كما دُفع له |

**مراحل الجلسة:** توزيع الأدوار ← مرافعة الادعاء ← مرافعة الدفاع ← استجواب الشهود ← كلمة المتهم الأخيرة ← مداولة ← **تصويت سرّي في الخاص** ← كشف الحقيقة والنقاط.
المراحل تتقدّم بمؤقّت، ويستطيع القاضي (أو المضيف/الأدمن) تخطّيها بزر **⏭**.

**الحكم:** أغلبية أصوات القاضي والشهود والمحلّفين. عند التعادل يحسم صوت القاضي، وإن لم يصوّت فالأصل البراءة.
**النقاط:** تُعرض بالتفصيل في `/rules` وتُعدَّل من `court/scoring.py` (قاموس `POINTS`). لوحة الشرف لكل قروب محفوظة وتظهر بـ `/top`.

## التوزيع عشوائي فعلاً

- المولّد `random.SystemRandom` (إنتروبيا نظام التشغيل، لا يمكن توقّعه) مع خلط Fisher–Yates لقائمة الأدوار، فلكل لاعب **نفس الاحتمال** لكل دور — لا أثر لترتيب الانضمام ولا لكون اللاعب هو المضيف.
- كذلك بالقرعة: **مذنب أم بريء**، **أي القضايا** (مع تجنّب آخر 6 استُعملت في القروب)، **اتجاه رشوة المرتشي**، وأسئلة القاضي.
- مغطّى باختبارات إحصائية (`tests/test_engine.py::TestRandomness`) تتحقق من التوزيع المنتظم على عشرات الآلاف من التجارب.

## الخصوصية: ماذا يظهر أين؟

- **في القروب فقط:** من هو القاضي/المدّعي/المحامي/المتهم/الشهود/المحلّفون، ملف القضية، الأدلة التي **عرضها** المحامون، أعداد المصوّتين، ثم النتيجة والكشف الكامل في النهاية.
- **في الخاص فقط:** بطاقة الدور السرّية، أزرار عرض الأدلة، فحص المحقق، لوحة التصويت (حكمك + تخمين شاهد الزور).
- اختبار آلي يمرّ على كل رسائل القروب قبل النهاية ويتأكد أنها لا تحتوي أي نص سرّي (قصص المتهم، روايات الشهود، الأدلة غير المعروضة، أسماء الأدوار السرّية).
- إن تعذّر إرسال بطاقة دور لأي لاعب (حظر البوت مثلاً) تُلغى المحكمة قبل أن تبدأ ويُذكر السبب بدل أن تستمر بلاعب أعمى.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/court` | فتح محكمة جديدة (ردهة تسجيل) |
| `/join` · `/leave` | الانضمام / الانسحاب قبل البدء |
| `/begin` | بدء الجلسة (للمضيف أو أدمن القروب) |
| `/skip` | تخطّي المرحلة (للقاضي أو المضيف أو الأدمن) |
| `/status` | حالة المحكمة الحالية |
| `/top` | لوحة الشرف |
| `/rules` | شرح اللعبة والأدوار والنقاط |
| `/cancel` | إلغاء المحكمة (المضيف أو القاضي أو الأدمن) |

## الإعدادات (`.env`)

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `BOT_TOKEN` | — | توكن البوت (مطلوب) |
| `MIN_PLAYERS` / `MAX_PLAYERS` | 5 / 20 | حدّا عدد اللاعبين (الأدنى التقني 4) |
| `TIME_SCALE` | 1 | معامل سرعة كل المراحل (1.5 = أبطأ بنصف) |
| `DUR_<PHASE>` | — | مدة مرحلة بعينها بالثواني، مثل `DUR_PROSECUTION=90` |
| `VOTE_GRACE` | 8 | مهلة بعد اكتمال التصويت لتصحيح الأخطاء |
| `LOBBY_TIMEOUT` | 600 | إغلاق الردهة الخاملة (ثوانٍ) |
| `DATA_DIR` | `./data` | مكان ملف النقاط `scores.json` |

للتشغيل الدائم على سيرفر (systemd):

```ini
[Unit]
Description=Court game Telegram bot
After=network-online.target

[Service]
WorkingDirectory=/opt/court-bot
EnvironmentFile=/opt/court-bot/.env
ExecStart=/usr/bin/python3 court_bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## هيكل المشروع

```
court_bot.py          نقطة التشغيل (إعدادات + تشغيل)
demo.py               لعبة كاملة بلاعبين وهميين بلا إنترنت
court/
  roles.py            الأدوار والتوزيع العشوائي
  cases.py + _cases_*.py   القضايا (10 قضايا؛ أضف المزيد بنسخ أي عنصر)
  game.py             محرك اللعبة (حالة وقواعد، بلا اتصال بتيليجرام)
  scoring.py          الحكم والنقاط
  render.py           رسائل القروب   |  cards.py  رسائل الخاص
  base.py / flow.py / bot.py   المتحكّم: أوامر، أزرار، مراحل، مؤقّت
  telegram_api.py     عميل Bot API بالمكتبة القياسية
  store.py            لوحة النقاط (JSON بكتابة ذرّية)
  fake_telegram.py    تيليجرام وهمي صارم للاختبار والعرض
tests/                48+ اختباراً
```

الاختبارات: `python3 -m unittest discover -s tests`

## التوسعة

- **قضية جديدة:** انسخ عنصراً في `court/_cases_b.py` وعدّل نصوصه (التهمة، روايتا الشاهد، قصتا المتهم، 3 أدلة لكل جهة).
- **دور جديد:** عرّفه في `roles.py` (الاسم والتركيب حسب العدد)، وأضف بطاقته في `cards.py`، ونقاطه في `scoring.py`.
- **تعديل التوازن:** غيّر أرقام `POINTS` أو مدد المراحل.

## قيود معروفة

- حالة الجلسة الجارية في الذاكرة: إعادة تشغيل البوت أثناء جلسة تلغيها (لوحة النقاط تبقى محفوظة).
- يعمل بنظام polling (لا webhook).
- الأسماء بالعربية الفصحى المبسّطة؛ تعديل النصوص في `render.py` و`cards.py` و`lines.py`.
